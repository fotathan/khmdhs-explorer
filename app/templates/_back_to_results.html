{# _back_to_results.html — a "back to the list" link that keeps the list. Lists and the detail pages they lead to: / (search) → /act/, /authority/ /authorities → /authority/ /contractors → /contractor/ /explore (overview) → /authority/, /contractor/ /analytics (statistics) → /authority/, /contractor/ /digests/ (alert) → /act/, /authority/ /act/ → /authority/, /contractor/ /contractor/ → /authority/ Every list keeps its state (filters, page) in the address bar: the HTMX lists push their querystring (hx-push-url), the others are plain GET links. The list page calls remember_results(path), which on load and after every swap copies window.location into sessionStorage under that path, and marks the path as the LAST list this tab visited. A page whose address varies (/digests/, /act/) is registered by prefix: remember_results('/act/', true), and ['/act/', label, true] on the other side. A detail page can be reached from more than one place, so back_link takes every place that leads to it, as [path, label] or [path, label, prefix] — the first is the default — and picks, most precise first: 1. the tab's last visited list, when it is one of them; 2. document.referrer, when it IS one of them — a detail page opened in a new tab may start with empty sessionStorage (Referrer-Policy strict-origin-when-cross-origin sends the full same-origin URL); 3. what THIS page picked last time ('khmdhs:backFrom:'). A detail page that is itself registered (an act, a contractor) overwrites the last-visited mark on load, so after act → contractor → authority → back, rules 1 and 2 no longer know the contractor came from the act. Without this rule the link fell through to whatever list happened to be stored; 4. any of them this tab has stored, in the order given — e.g. search → act → authority still returns to the authorities list you filtered; 5. the server-rendered `fallback` href — no script, or nothing visited. The label follows the place it returns to. Only a same-origin URL on one of the given paths is ever accepted. Stored per tab, never sent anywhere. Imported without context: the caller passes already-translated labels and the fallback href. #} {% macro remember_results(path, prefix=false) -%} {%- endmacro %} {% macro back_link(lists, fallback) -%} {{ lists[0][1] }} {%- endmacro %}
